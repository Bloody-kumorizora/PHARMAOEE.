# Changelog

## v9.0.0 — 2026-10-25

Крупное обновление: приложение разделено на модули, переработаны интерфейс, модель данных и расчёты.
Данные v8 переносятся автоматически (с резервной копией).

### Расчёты
- Формулы OEE вынесены в `oee.py`; значения больше **не обрезаются до 100%** (в v8 доступность и
  производительность скрыто ограничивались). Выход за 100% показывается с предупреждением.
- Сводные показатели считаются по суммам минут и идеального времени; A × P × Q = OEE и для записей с разным циклом.
  В v8 качество на панели не ограничивалось, а остальные коэффициенты ограничивались — расчёт был несогласован.
- Валидация отделена от формул: понятные ошибки на русском вместо системных сообщений Python
  («could not convert string to float»), явные правила для нулевых значений.

### Данные
- База перенесена из папки программы в каталог пользовательских данных (`%LOCALAPPDATA%\PharmaOEE`,
  `~/.local/share/pharmaoee`); параметр `--data-dir` и переменная `PHARMAOEE_DATA_DIR`.
- Версионируемая схема (`PRAGMA user_version`), миграция v8 → v9 в одной транзакции с резервной копией.
- Справочник оборудования и причин, внешние ключи, CHECK-ограничения, индексы, журнал изменений.
- Пометка происхождения каждой записи: ручной ввод / демо-данные / симулятор.
- Соединения SQLite закрываются после каждой операции (в v8 `with sqlite3.connect()` не закрывал соединение).
- Защита от дубликатов смен (дата + смена + оборудование) и от пересекающихся простоев.

### Простои
- Дата и время начала/окончания, переход через полночь, незавершённые простои и их завершение.
- Редактирование и удаление с подтверждением; учёт без двойного счёта; сводки по причинам и оборудованию.
- Смена и дата смены для событий симулятора определяются по расписанию (в v8 всегда «1 смена»).
- Классификация больше не стирает служебные пометки в комментарии.

### Аналитика и отчёты
- Общий фильтр периода, оборудования, смены и происхождения данных для всех разделов.
- Графики: динамика OEE и составляющих, Парето причин, рейтинг оборудования, сравнение смен, выпуск и брак,
  доля брака. Таблицы проблемных смен, повторяющихся проблем и автоматической проверки данных.
- Экспорт CSV учитывает фильтры (в v8 выгружалась вся таблица), содержит период, время формирования,
  предупреждение о демо-данных и защиту от формул Excel.

### Демо-данные и симулятор
- Генератор: выбор линий и смен, зерно, воспроизводимость, разнообразные сценарии, пропуск существующих и
  незавершённых смен, безопасное удаление только сгенерированных данных.
- Симулятор смены с лентой состояний; ручные сигналы сохранены. Потеря связи больше не считается простоем.
- Интерфейс `DataSource` для будущих источников данных.

### Резервное копирование
- Копия через backup API с проверкой целостности; восстановление с проверкой файла, копией текущей базы и
  откатом при ошибке; восстановление базы v8; обработка повреждённой базы при запуске.

### Интерфейс
- Новый дизайн: боковая навигация, карточки KPI с пояснениями формул, сортируемые таблицы с поиском, выбор даты
  в календаре, формы с предпросмотром расчёта, индикатор фоновых операций, строка состояния.

### Тесты и документация
- 148 автоматических тестов (было 7), включая интеграционные тесты интерфейса.
- Новые README, описание архитектуры, Release Notes.
