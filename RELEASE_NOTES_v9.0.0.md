# PharmaOEE 9.0.0 — Release Notes

Учебное настольное приложение для мониторинга OEE и учёта простоев. Python + Tkinter + SQLite,
без сторонних зависимостей. **Учебный прототип, не GMP-валидированная система.**

## Главное

- **Корректная математика OEE**: без скрытого ограничения до 100%, с предупреждениями и согласованным
  агрегированием; контрольные примеры покрыты тестами.
- **Сохранность данных**: база в каталоге пользователя, версионируемая схема, автоматическая миграция v8 с
  резервной копией, транзакции, внешние ключи, безопасные резервное копирование и восстановление.
- **Полноценный учёт простоев**: переход через полночь, незавершённые простои, запрет пересечений, учёт без
  двойного счёта, редактируемый справочник причин.
- **Единый фильтр периода** для показателей, графиков, таблиц и экспорта; обе границы включаются.
- **Новый интерфейс**: 8 разделов, графики, сортируемые таблицы с поиском, календарь, формы с предпросмотром.
- **Честные демо-данные**: воспроизводимый генератор, симулятор смены, пометка происхождения, удаление без
  риска для ручного ввода.
- **148 автотестов**, включая тесты интерфейса.

## Обновление с v8

1. Сделайте копию своего `pharmaoee.db` из папки v8.
2. Распакуйте v9 в новую папку и положите `pharmaoee.db` из v8 рядом с `pharmaoee.py` **до первого запуска** —
   база будет скопирована в каталог данных и обновлена (исходный файл не меняется).
   Либо после запуска: «Резервные копии → Восстановить из файла…» и выберите базу v8.

## Проверено

- Windows 11, Python 3.15.0, Tk 9.0, SQLite 3.53: `python -m unittest -v` — 148 тестов, все пройдены;
  запуск окна и просмотр разделов и основных диалогов.

## Не проверено

- Linux, RED OS, macOS; сборка исполняемого файла PyInstaller.

## Как опубликовать релиз на GitHub

1. Создайте пустой репозиторий на <https://github.com/new> (без README, чтобы не было конфликта).
2. В папке проекта выполните по очереди:

   ```bash
   git init
   ```

   ```bash
   git add .
   ```

   ```bash
   git commit -m "PharmaOEE 9.0.0"
   ```

   ```bash
   git branch -M main
   ```

   ```bash
   git remote add origin https://github.com/<ваш-логин>/PharmaOEE.git
   ```

   ```bash
   git push -u origin main
   ```

3. Перед `git add` проверьте командой `git status`, что в список не попали `.db`, `backups/`, `logs/`, `.csv`.
4. На странице репозитория: **Releases → Draft a new release** → тег `v9.0.0` → заголовок «PharmaOEE 9.0.0» →
   вставьте этот текст → прикрепите `PharmaOEE_v9.0.0_GitHub.zip` → **Publish release**.
